🀄 Mahjong Memory

Companion app for the interactive memory mat

One mat, an app full of games

This screen represents what the mat's app shows once paired. Tapping a tile icon here stands in for the mat sensing a tile placement (faked NFC for this lofi build) and sending that data to the phone.
In the final product, each mat cell reads the tile placed on it via embedded NFC and sends that automatically. For this prototype, a facilitator taps the matching icon as each physical tile is placed — same data, no electronics needed to demo.
Guided recall

Game 1 — Collect the Set

Each player owns a category — Food or Transport — with 5 columns, one per tile design. Complete a column of 4 identical tiles to hear a memory question. If the player hesitates or cannot answer, the app suggests gentle follow-up prompts and records the outcome.

Matching only

Game 2 — Pairs

All tiles face down. Tap the two tiles flipped — a match earns a point; a miss means both go back face down and play passes to the next player (or bot). There are no recall questions in this game.

After both games
